# The Twelfth Stamp

**Eleven countries. Eleven stamps. You came home with twelve.**

A first-person psychological horror puzzle game for PC, the browser and Meta Quest 3 (VR), built in Unity 6.

🏆 **1st place overall, GameForward GameJam: Mythos Collide** (also ranked #1 for The Collision and Fun)

▶️ **Play in your browser:** https://mohammad-umer7.itch.io/the-twelfth-stamp
🎬 **Trailer:** https://youtu.be/EW7DYY-Rcy4

## The game

You are Saeed, home from the Festival of Passports, where every country stamps your passport. There are eleven seals, but there are twelve stamps, and the twelfth says HOME: ENTRY GRANTED. You never earned it. It was forged by the Passenger, a figure of smoked glass that copies the places you remember, and it walked home in your shape.

Your passport is your only tool. Tear its seams open to borrow light and sound from the countries you visited: pull Egyptian sunlight into a rainy Paris night to drive the Passenger back, or hide the sound of a tear under London's midnight chime. Every tear lets something through, in both directions.

Verify all eleven seals, cancel the forgery in Berlin, and find the one door home it cannot fake.

## Modes

- **Story:** the whole journey through all eleven countries
- **Easy, Medium, Hard** levels and **Free Roam**, all from the welcome screen
- **Desktop**, **browser** (with WebXR for Quest Browser) and **PC VR** through Quest Link / Air Link (OpenXR)

## Controls (desktop)

| Key | Action |
| --- | --- |
| WASD / Mouse / Shift | Move, look, run |
| F | Open or close the passport |
| Mouse wheel or `[` `]` | Choose a country |
| Hold left mouse on a seam | Tear it open (keep holding to widen) |
| Hold right mouse | Seal a tear |
| E / R | Interact, recall |
| Tab / M / G | Objectives, map, take the glasses off |
| Esc | Pause |

VR: X opens the passport, B chooses a country, grip a seam and pull it apart (or hold the right trigger), A seals, Trigger interacts.

## Tech

- Unity 6000.6.2f1, URP 17.6, OpenXR 1.18, Input System 1.20, WebXR Export
- Levels are assembled from code at runtime: procedural meshes for rooms, streets and skylines
- Procedural textures and synthesised sound generated by the tools in `Tools/`
- 3D props, landmarks and characters built with Blender Python scripts (`Tools/blender`)
- Custom URP shaders for the passport tears, beams, planar mirrors and the sky dome
- In-build automated tests (`--autotest`) used for QA

## Building

Open `Game/` in Unity 6000.6.2f1 (WebGL and Windows build support modules), or build headless:

```
Unity.exe -batchmode -quit -projectPath Game -executeMethod TwelfthStamp.EditorTools.BuildScript.BuildWindows -buildPath "C:\...\TheTwelfthStamp.exe"
Unity.exe -batchmode -quit -projectPath Game -executeMethod TwelfthStamp.EditorTools.BuildScript.BuildWebXR -buildPath "C:\...\WebXR"
```

The editor menu **Twelfth Stamp > Build Web (WebXR)** does the browser build too.

## Content warning

Psychological horror with horror audio, sudden loud sounds and jump scares. No visual gore. Set Scare intensity to Gentle in the first-run screen or Settings for a softer version.
