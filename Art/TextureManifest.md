# Texture Manifest - The Twelfth Stamp

All files below are **original procedural artwork** generated by `Tools/textures/gen_textures.py` (numpy + Pillow + scipy, fixed seeds derived from each asset name with CRC32). No images were downloaded, traced or AI-generated, and no texture contains lettering. Regenerate everything with:

```
uv venv Tools/.venv            # once
uv pip install --python Tools/.venv numpy pillow scipy
Tools/.venv/Scripts/python.exe Tools/textures/gen_textures.py
Tools/.venv/Scripts/python.exe Tools/textures/gen_textures.py --only stamp_uae paper_ivory   # subset
```

Source modules: `gen_textures.py` (entry point, tiling check, previews), `tx_core.py` (periodic noise, periodic Voronoi, normals, drawing), `tx_materials.py`, `tx_graphics.py` (pages, cover, acetate, notes, overlays, UI, icon), `tx_stamps.py`, `tx_paint.py` (portraits, passenger photo, postcards), `tx_report.py`.

## Conventions and Unity import settings

- `*_a.png`: albedo, 8-bit **sRGB** RGB. Import with *sRGB (Color Texture)* on. Luminance is soft-limited to roughly 0.13-0.86 (sRGB-encoded 0..1 scale; no pure black/white) so country lighting can do the work.
- `*_n.png`: tangent-space normal, **OpenGL / Unity convention (+X right, +Y up = green)**, derived from a height field with wrap-around Sobel. Import as *Texture Type: Normal map* (do not tick *Create from Grayscale*).
- `glass_smudge_a.png`: 8-bit grayscale mask (0 = clean glass, 1 = full smudge). Import with sRGB **off**.
- RGBA graphics carry straight (non-premultiplied) alpha; transparent pixels keep the ink/overlay colour so bilinear filtering does not create dark fringes. Enable *Alpha Is Transparency*.
- `passport_cover_ms.png` (optional extra): URP Lit *Metallic Map* layout, R = metallic, A = smoothness. Linear (sRGB off).
- Material textures wrap in both axes: set *Wrap Mode: Repeat*.

## Tiling check

For every tileable file the script compares the wrap-around neighbours (last column vs first column, last row vs first row) with ordinary neighbouring pixel pairs. Ratio = seam mean-abs-difference / median interior neighbour difference (8-bit levels). A seamless tile gives ~1.0; a hard seam typically gives 5-50. A file passes if the seam difference is <= max(1.5 x median, 99th percentile of interior pairs) + 0.5. Ratios above 1.5 that still pass come from a legitimate feature (joint, ring boundary) that happens to cross the border, and stay inside the range of interior neighbour pairs. Layout grids are offset so joints avoid the border.

**Result: 52/52 tileable files pass** (largest ratio 2.06 on `wood_dark_n.png`).

## Notes

- `passport_insert_layout.json` lists the 11 seal ovals in the required order (UAE, Egypt, France, USA, Japan, SaudiArabia, India, Brazil, UnitedKingdom, Morocco, Germany) plus the return field, in Unity UV (origin bottom-left) and in pixels. `calibration_insert.png` is drawn from the same layout, so its 11 constellation points sit exactly on the oval centres and the cancelled 12th point on the return-field centre.
- `passport_id_layout.json` gives the photo window (4:5, matches `saeed_portrait.png`) for in-engine compositing.
- Lens overlays: the centre is exactly transparent inside a circle 84% of the width wide (about 55% of all pixels), so the central 55% of the view is always clear.
- Stamps use ink #7a1f1f; the forged home stamp uses a slightly too-bright red (#a82828), a 3.5 degree tilt, a shear and a second misregistered impression.
- Symbols are original simplified drawings, not national emblems, crests or flags. The portrait is an original stylised character, not based on any real person.
- `Art/texture_contact_sheet.png` shows every material tiled 2x2 and every graphic.
